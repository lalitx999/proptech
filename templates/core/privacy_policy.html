1 บทนำและขอบเขตการบังคับใช้

เซ้งร้านด่วน.com (ต่อไปนี้เรียกว่า "แพลตฟอร์ม" หรือ "เรา") ดำเนินงานโดยตระหนักและเคารพในสิทธิความเป็นส่วนตัวของผู้ใช้งานทุกคน (ต่อไปนี้เรียกว่า "ท่าน" หรือ "เจ้าของข้อมูลส่วนบุคคล") นโยบายฉบับนี้จัดทำขึ้นเพื่อชี้แจงแนวปฏิบัติเกี่ยวกับการเก็บรวบรวม ใช้ และเปิดเผยข้อมูลส่วนบุคคล (Personal Data) ตาม พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

การเข้าถึง ใช้งาน หรือลงทะเบียนบัญชีบนแพลตฟอร์ม ถือว่าท่านได้รับทราบและตกลงปฏิบัติตามแนวทางที่ระบุไว้ในนโยบายความเป็นส่วนตัวฉบับนี้แล้ว

2 ข้อมูลส่วนบุคคลที่เราจัดเก็บ

เราเก็บรวบรวมข้อมูลส่วนบุคคลเท่าที่จำเป็นต่อการดำเนินงานของแพลตฟอร์ม ได้แก่:

  • ข้อมูลสำหรับการลงทะเบียนและยืนยันตัวตน: หมายเลขโทรศัพท์มือถือ, ที่อยู่อีเมล, รหัส OTP (One-Time Password), ชื่อผู้ใช้ และรหัสผ่านที่ผ่านการแฮชด้วยอัลกอริทึม Argon2 / PBKDF2 อย่างปลอดภัย
  • ข้อมูลประกาศร้านค้าและธุรกิจ: ชื่อกิจการ, ที่ตั้งสถานที่, ละติจูด/ลองจิจูด (GPS Coordinates), ภาพถ่ายหน้าร้านและอุปกรณ์, ยอดขายเฉลี่ย และกำไรสุทธิ 3 เดือนล่าสุด
  • ข้อมูลการชำระเงินและสมัครสมาชิก VIP: สลิปหลักฐานการโอนเงินธนาคาร, วันที่-เวลาโอน, จำนวนเงิน, ธนาคารต้นทาง/ปลายทาง (ประมวลผลผ่าน EasySlip API แบบอัตโนมัติ)
  • ข้อมูลทางเทคนิคและการใช้งาน: หมายเลข IP Address, ชนิดเบราว์เซอร์, บันทึกการเข้าสู่ระบบ (Security Audit Logs), คุกกี้ และประวัติการสืบค้นข้อมูลร้านค้า

3 วัตถุประสงค์และฐานทางกฎหมาย (Legal Basis)

เราประมวลผลข้อมูลส่วนบุคคลของท่านภายใต้ฐานความชอบธรรมตามกฎหมาย ดังนี้:

1. ฐานการปฏิบัติตามสัญญา (Contractual Necessity) เพื่อสร้างบัญชีผู้ใช้งาน, เผยแพร่ประกาศเซ้งร้านตามที่ท่านส่งข้อมูล, อำนวยความสะดวกในการติดต่อระหว่างผู้ซื้อและผู้ให้เซ้ง, และการเปิดใช้งานสิทธิประโยชน์แพ็กเกจสมาชิก VIP
2. ฐานความยินยอม (Consent) สำหรับการส่งการแจ้งเตือนความคืบหน้าของประกาศ, จดหมายข่าวข้อเสนอร้านค้าทำเลทองที่ตรงกับความสนใจ, หรือการยืนยันตัวตนด้วยอีเมล OTP
3. ฐานประโยชน์อันชอบด้วยกฎหมาย (Legitimate Interest) เพื่อตรวจสอบและป้องกันพฤติกรรมมิจฉาชีพ การปลอมแปลงสลิปโอนเงิน การป้องกันการโจมตีทางไซเบอร์ และการปรับปรุงประสิทธิภาพระบบ (Core Web Vitals)

4 การเปิดเผยข้อมูลแก่บุคคลภายนอก

เราไม่มีนโยบายจำหน่าย แลกเปลี่ยน หรือส่งต่อข้อมูลส่วนบุคคลของท่านให้กับบุคคลภายนอกเพื่อผลประโยชน์ทางการค้า โดยข้อมูลจะถูกเปิดเผยเฉพาะกรณีที่จำเป็น ดังนี้:

  • ผู้ใช้บริการรายอื่น: ข้อมูลติดต่อ (เบอร์โทร หรือ LINE ID) ที่ท่านเลือกเปิดเผยบนหน้าประกาศร้านค้าเพื่อให้ผู้สนใจสามารถติดต่อสอบถามได้
  • ผู้ให้บริการเทคโนโลยีและโครงสร้างพื้นฐาน: เช่น ระบบคลาวด์เซิร์ฟเวอร์, ผู้ให้บริการตรวจสอบสลิป EasySlip, ผู้ให้บริการแผนที่ Google Maps API (ภายใต้สัญญาคุ้มครองข้อมูลส่วนบุคคล Data Processing Agreement)
  • หน่วยงานบังคับใช้กฎหมาย: เจ้าหน้าที่ตำรวจ ศาล หรือหน่วยงานรัฐที่มีอำนาจตามหมายศาลหรือกฎหมายกรณีเกิดข้อพิพาทฉ้อโกง

5 ระยะเวลาและมาตรการรักษาความมั่นคงปลอดภัย

เราจัดเก็บข้อมูลส่วนบุคคลของท่านไว้ตราบเท่าที่ท่านยังมีสถานะเป็นสมาชิกของแพลตฟอร์ม และจะเก็บรักษาข้อมูลบันทึกทางเทคนิค (Log Files) ต่อไปอีกไม่เกิน 90 วันตาม พ.ร.บ. คอมพิวเตอร์ฯ ก่อนทำการลบหรือทำให้อยู่ในรูปแบบที่ไม่สามารถระบุตัวบุคคลได้ (Anonymization)

เราใช้มาตรการความปลอดภัยทางเทคนิคและการบริหารจัดการระดับสากล ได้แก่ การเข้ารหัสข้อมูลระหว่างส่งผ่าน HTTPS/TLS, การแยก Environment ข้อมูล, ระบบ Content Security Policy (CSP Nonce), และการจำกัดสิทธิ์การเข้าถึงข้อมูลเฉพาะแอดมินที่ได้รับอนุญาต

6 สิทธิของเจ้าของข้อมูล (Data Subject Rights)

ตามกฎหมาย PDPA ท่านมีสิทธิตามกฎหมายดังต่อไปนี้:

สิทธิขอเข้าถึงและรับสำเนา (Right to Access) ขอรับสำเนาข้อมูลส่วนบุคคลของท่านที่อยู่ในความดูแลของเรา
สิทธิขอแก้ไขข้อมูล (Right to Rectification) ขอแก้ไขข้อมูลส่วนบุคคลให้ถูกต้อง เป็นปัจจุบัน และสมบูรณ์
สิทธิขอลบหรือทำลาย (Right to Erasure) ขอลบข้อมูลส่วนบุคคลหรือยกเลิกบัญชีผู้ใช้งาน
สิทธิถอนความยินยอม (Right to Withdraw) ถอนความยินยอมที่เคยให้ไว้ได้ตลอดเวลาผ่านการตั้งค่าบัญชี

7 การใช้งานคุกกี้ (Cookies Policy)

เราใช้งานคุกกี้ที่จำเป็น (Strictly Necessary Cookies) เพื่อการเข้าสู่ระบบ การจัดการ Session และการป้องกัน CSRF และคุกกี้เชิงฟังก์ชันเพื่อจดจำตัวกรองการค้นหาร้านเซ้งของท่าน ท่านสามารถตั้งค่าปิดการใช้งานคุกกี้ได้ผ่านการตั้งค่าเบราว์เซอร์ของท่าน
